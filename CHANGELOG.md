# Changelog

This file records project-level release guidance. GitHub Releases contain the
historical tag-by-tag notes and assets.

## Unreleased

- Improved the public OSS contributor path, security documentation, issue
  templates, pull request checklist, roadmap, and repository metadata.
- Moved the documented integration target from the historical work branch to
  `main` without changing readiness claims.
- Kept development previews explicitly separate from formal, signed releases.

## Development previews

Development-preview tags may contain debug Android APKs or unsigned Windows
installers for development, drills, and validation only. They are not formal
releases, are not emergency-service deployments, and must not be treated as
production artifacts. Each preview should state:

- what changed;
- known limitations;
- security-related changes;
- verification status;
- build and download notes;
- whether artifacts are signed.

See the [GitHub Releases page](https://github.com/heynegix/Relay/releases) for
the current list of previews and historical releases.
